    The Replay v3.0 Update is here!

    October 14, 2026 1 minute read
    Table of contents
    1. Changes
    2. Bug Reports

    This update focuses on the new replay system, along with some smaller changes.
    We’re also collecting feedback and suggestions! Join our Discord Server!

    Changes

    • Replay v3.0 Update
      • This update brings a complete overhaul to the replay system, with lots of new features, bug fixes, QOL improvements and more. Not to mention a complete tutorial to get you acquainted!
      • Summary of all the replay changes:
        • New replay UI & controls
        • Replay tutorial
        • First-person POV
        • Player health, hunger, breath, inventory & more stats
        • Visualize mob/player pathing
        • Splits viewer, navigation & alignment
        • Piglin trades stat screen
        • X-ray spawners/chests/gold blocks
        • Pie chart recording
        • Player UI interaction recording
        • Looted/unlooted toggle for chests
        • New timeline icons (by ollie)
        • And more!
    • Fixed an issue where ocean seed types would sometimes have both a shipwreck and buried treasure at spawn.
    • All strongholds now generate with the same rooms and layout, and still have the same number of eyes.
      • However, they can still be affected by other generated structures, such as caves, dungeons and mineshafts. We are looking into a way to fix this in the future.
    • Added more splash texts.

    Bug Reports

    Please join our Discord Server to report any issues!
